
How to open and edit multiple projects in the same window?
# https://stackoverflow.com/questions/8774024/how-to-open-and-edit-multiple-projects-in-the-same-window

Select File->Project Structure->Modules.
Select + and Import Module and select the directory of your project(or directory where pom exists) and click OK.

 - go to a char
 - press 'v' to select

map mp <A-p>
-- end config

== How do I change rate of the keys repeat rate
# https://askubuntu.com/questions/1053448/how-do-i-change-rate-of-the-keys-repeat-rate-through-console

xset r rate 240 100
240 - is a milliseconds delay before repeating starts
100 - a number between 1 and 255. The higher the number, the faster the repetition

Clear initramfs and Old Kernels
Old kernels and their associated initramfs files can fill up the /boot partition.
- Remove unused kernels:
    sudo apt-get autoremove --purge
- Update initramfs: If you need to make initramfs smaller,
    set COMPRESS=xz in /etc/initramfs-tools/initramfs.conf and run sudo update-initramfs -u
